# 角色卡过审与防盗助手

原始附件：`过审助手V1.6免改网站一键防盗.html`。本目录原样归档，不修改其检查规则或封装实现。

下载 HTML 后用浏览器打开即可。基础检查在浏览器本地进行；配置 AI 修复并发起修复时，会将待修复卡片内容发送给所选 API 服务。不要在公开仓库提交 API 密钥或个人卡片源文件。

## 功能边界

- 主要检查卡片结构、世界书触发关键词、内容体量和投稿质量。
- 关键词检查关注触发可靠性，不是敏感词过滤器。
- 防盗包括作者信息、可见水印、来源指纹及 RP-Hub 兼容 PNG 封装。
- 该版本元数据明确标记 `encrypted: false`；封装后的卡片仍包含可读取 JSON，不能作为强加密或绝对防复制承诺。
- 原附件文件名为 V1.6，页面标题为 V1.5，审核核心版本为 2.5.0。维护时用原文件哈希确认版本，不按标题猜测。

自动制卡的设计讨论见 [项目方案](../../docs/card-studio-plan.md)。
